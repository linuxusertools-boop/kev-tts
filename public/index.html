Permintaan

Berubah otomatis mengikuti isian di kiri.

URL

      
curl

      

      
Header respons

      
Isi JSON

    

  


  

    

      
Parameter

      

        
text / qTeks yang dibacakan. Dipotong otomatis di batas MAX_CHARS (bawaan 300).

        
prompt_textTranskrip isi sample. Bila diisi, kualitas clone naik.

        
controlInstruksi gaya suara, bila model mendukung.

        
cfg, stepsPengaturan generate. Kosong = bawaan Space.

        
clone0 untuk tidak memakai sample.

        
fallback0 mematikan suara cadangan.

        
formataudio (bawaan) atau json berisi data URI base64.

        
download1 memaksa unduh file.

      

    

    

      
Respons dan error

      
    
        
  • 200 berisi audio. Header X-TTS-Engine menunjukkan voxcpm atau youdao-fallback (bukan hasil clone).
    • 
        
  • 429 kuota GPU atau rate limit Space habis. Tambahkan HF_TOKEN di Vercel.
    • 
        
  • 503 Space sedang tidur atau bangun. Ulangi beberapa detik lagi.
    • 
        
  • 500 SAMPLE_MISSING: file di storage/ tidak ikut ter-deploy.
    • 
        
  • Semua error berbentuk JSON: status, code, message, attempts.
    • 
      

      
Endpoint: /api/tts, /tts, /animemoe (lama), /api/status untuk diagnosa.

    

    

      
Environment variable (opsional)

      

        
HF_TOKENToken Hugging Face; beberapa token dipisah koma di HF_TOKENS dan dirotasi.

        
VOXCPM_SPACESDaftar URL Space cadangan, dipisah koma.

        
SAMPLE_PATHNama atau path file sample lain.

        
SAMPLE_TRANSCRIPTTranskrip sample sebagai prompt_text bawaan.

        
MAX_CHARSBatas karakter teks (20–1000).

        
VOXCPM_API_NAMEPaksa nama endpoint Gradio, mis. /generate.
