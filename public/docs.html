Dokumentasi

API teks → suara. Tanpa token, tanpa API key, tanpa konfigurasi.

Endpoint

PathFungsi
/animemoe?text=HaloSuara utama (storage/sample.mp3)
/{suara}?text=HaloSuara lain. Contoh storage/kawai.mp3 → /kawai?text=Halo
/tts?voice=kawai&text=HaloBentuk umum (juga /api/tts), GET atau POST JSON
/voicesDaftar semua suara + URL masing-masing (JSON)
/homeCoba langsung & salin URL
/statusDiagnosa mesin & daftar suara
/healthCek hidup instan
/warmPemanasan (untuk pinger)

Parameter

NamaKeterangan
textTeks yang diucapkan (maks 300 karakter, bisa diubah lewat MAX_CHARS)
voiceNama suara (hanya di /tts); kosong = utama
fast=1Mode kilat: ~1 detik, suara biasa (bukan clone)
format=jsonBalasan JSON berisi audio base64
download=1Paksa unduh file
langBahasa mode kilat/cadangan: ja, en, ko, zh, fr
fallback=0Matikan suara cadangan (error jelas jika clone gagal)

Contoh

curl "https://DOMAIN-KAMU/animemoe?text=Konnichiwa" -o suara.mp3
curl "https://DOMAIN-KAMU/kawai?text=Halo&fast=1" -o kawai.mp3
curl "https://DOMAIN-KAMU/voices"
const r = await fetch('/animemoe?text=' + encodeURIComponent('Halo'));
new Audio(URL.createObjectURL(await r.blob())).play();

Menambah suara

Taruh file audio di folder storage/. Nama file = nama endpoint. Format: mp3, wav, m4a, ogg, flac. Pakai suara bersih, satu orang, 5–15 detik. Deploy ulang, selesai — suara otomatis muncul di /voices dan /home.

storage/sample.mp3  → /animemoe  (utama)
storage/kawai.mp3   → /kawai
storage/tsundere.mp3 → /tsundere

Pemasangan

  1. Upload proyek ke GitHub, lalu import di Vercel (Framework: Other, tanpa build command).
  2. Tidak ada environment variable yang wajib. Tidak memakai HF token.
  3. Buka /home untuk mencoba, /status untuk memeriksa mesin.
  4. Agar respons pertama tetap cepat, pasang pinger gratis (cron-job.org / UptimeRobot) ke /warm tiap 5 menit.

Respons & header

Sukses: audio langsung. Header berguna: X-TTS-Voice, X-TTS-Engine (voxcpm atau cadangan), X-TTS-Cache, X-TTS-Elapsed-Ms. Teks yang sama dipakai ulang dari cache sehingga balasannya instan.

Gagal: JSON {status:false, code, message}. Suara tak dikenal → 404 VOICE_NOT_FOUND beserta daftar suara yang ada.

Soal kecepatan & ketahanan

Suara clone dibuat di server model publik, jadi teks baru butuh beberapa detik; teks yang pernah diminta langsung instan dari cache. Untuk balasan sekitar satu detik gunakan fast=1. Bila model sibuk atau down, sistem otomatis mencoba ulang, memakai hasil tersimpan, atau suara cadangan, sehingga selalu ada jawaban.
